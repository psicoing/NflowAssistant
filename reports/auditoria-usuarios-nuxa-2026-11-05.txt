5. CÓDIGO Y PERSISTENCIA REVISADOS

Ruta activa:
- server/index.ts importa registerRoutes desde server/routes.ts.
- server/routes_clean.ts no es la implementación activa revisada.

Contadores:
- /api/admin/stats -> storage.getAllUsers() -> SELECT sobre users -> length.
- /api/public-stats -> storage.getPublicStats() -> COUNT(*) sobre users.
- El panel administrativo solicita estadísticas al cargar. No tiene
  actualización periódica propia para esta cifra.
- El componente público de estadísticas tiene refetchInterval de 30 segundos.
- La respuesta publicada comprobada de nuxa.life tiene Cache-Control private,
  sin cabecera Age. Esto y su coincidencia con SQL no sustentan que el 75
  observado actualmente se deba a caché.

Registros:
- /api/auth/register valida, comprueba username, calcula hash y usa
  storage.createUser(), que inserta en users y devuelve la fila.
- El flujo gratuito inicia una verificación persistida y no crea la cuenta
  definitiva hasta verificar correo y móvil. La finalización usa transacción
  para insertar/actualizar users y asociar la identidad de prueba.
- Un usuario que solo deja su correo o no termina la verificación no tiene
  por qué aparecer en users.
- Hay formularios empresariales que emiten registration_succeeded al guardar
  una solicitud comercial. Ese nombre de evento no debe interpretarse como
  garantía universal de una nueva cuenta en users.
- Los accesos con contraseña y magic link actualizan last_login_at y
  login_count. La activación de prueba establece sesión por su propia ruta,
  sin pasar por updateUserLogin.

El análisis estático muestra el destino de las escrituras, pero no sustituye
una prueba funcional completa. No se ha registrado una cuenta real ni se han
solicitado códigos para evitar escrituras o mensajes no autorizados.

10. CONSULTAS PRINCIPALES REALIZADAS

Todas las consultas de datos fueron SELECT de solo lectura. Las ventanas

Se incluyen las consultas agregadas relevantes, sin valores personales.

SQL PostgreSQL: conteo, fechas y categorías

SELECT count(*) AS total, min(created_at) AS first_user,
       max(created_at) AS last_user,
       count(*) FILTER(WHERE created_at IS NULL) AS missing_created_at,
       count(*) FILTER(WHERE last_login_at IS NOT NULL) AS ever_login_recorded,
       sum(coalesce(login_count,0)) AS lifetime_login_counter
FROM users;

SELECT p.days,
 count(*) FILTER(WHERE u.created_at>=now()-make_interval(days=>p.days)) AS new_users,
 count(*) FILTER(WHERE u.last_login_at>=now()-make_interval(days=>p.days)) AS recent_last_login
FROM (VALUES(7),(15),(30)) p(days)
CROSS JOIN users u GROUP BY p.days ORDER BY p.days;

SELECT subscription_status,coalesce(role,'user') AS role,count(*) AS accounts
FROM users GROUP BY subscription_status,coalesce(role,'user')
ORDER BY accounts DESC;

SELECT coalesce(role,'user') AS role,count(*) AS accounts,
 count(*) FILTER(WHERE subscription_status='active') AS active_status,
 count(*) FILTER(WHERE subscription_status='active'
   AND(subscription_expires_at IS NULL OR subscription_expires_at>now()))
   AS active_not_expired_or_undated,
 count(*) FILTER(WHERE has_completed_payment=true) AS payment_flag_true
FROM users GROUP BY coalesce(role,'user') ORDER BY accounts DESC;

SELECT p.days,
 count(DISTINCT u.id) FILTER(WHERE u.last_login_at>=now()-make_interval(days=>p.days))
   AS logged_in_accounts,
 count(DISTINCT u.id) FILTER(WHERE u.last_login_at>=now()-make_interval(days=>p.days)
   AND u.role='admin') AS logged_in_admin_accounts,
 (SELECT count(DISTINCT c.user_id) FROM conversations c
  JOIN messages m ON m.conversation_id=c.id JOIN users au ON au.id=c.user_id
  WHERE m.is_user=true AND m.timestamp>=now()-make_interval(days=>p.days))
   AS accounts_sending_messages,
 (SELECT count(*) FROM messages m JOIN conversations c ON c.id=m.conversation_id
  JOIN users au ON au.id=c.user_id
  WHERE m.is_user=true AND m.timestamp>=now()-make_interval(days=>p.days))
   AS user_messages
FROM (VALUES(7),(15),(30)) p(days) CROSS JOIN users u
GROUP BY p.days ORDER BY p.days;

SELECT count(*) AS retained_trial_flows,
 count(*) FILTER(WHERE completed_user_id IS NOT NULL) AS completed,
 count(*) FILTER(WHERE completed_user_id IS NULL AND email_verified_at IS NULL)
   AS email_not_verified,
 count(*) FILTER(WHERE completed_user_id IS NULL AND email_verified_at IS NOT NULL
   AND phone_verified_at IS NULL) AS phone_not_verified,
 count(*) FILTER(WHERE completed_user_id IS NULL AND phone_verified_at IS NOT NULL)
   AS verified_not_completed,
 min(created_at) AS earliest,max(created_at) AS latest
FROM nuxa_trial_flows;

SELECT count(*) FROM nuxa_trial_identities;
SELECT state,count(*) FROM nuxa_trial_sms_sends GROUP BY state;

SELECT 'individual_registrations' AS source,count(*) AS retained_rows,
 count(*) FILTER(WHERE created_at>=now()-interval '30 days') AS last30
FROM individual_registrations
UNION ALL
SELECT 'empresa_registrations',count(*),
 count(*) FILTER(WHERE created_at>=now()-interval '30 days')
FROM empresa_registrations;

SELECT to_char(created_at,'YYYY-MM') AS month,count(*) AS created_surviving_accounts,
 sum(count(*)) OVER(ORDER BY to_char(created_at,'YYYY-MM'))
   AS cumulative_surviving_accounts
FROM users GROUP BY 1 ORDER BY 1;

SELECT count(*) AS live_sessions,
 count(DISTINCT s.sess->>'userId') FILTER(WHERE s.sess->>'userId' IS NOT NULL)
   AS signed_in_distinct_accounts,
 count(*) FILTER(WHERE s.sess->>'isAdmin'='true') AS admin_sessions
FROM nuxa_auth_sessions s WHERE s.expire>now();

SQL ClickHouse: eventos y propiedades

SELECT event_name,count() AS occurrences,
 uniqExact(session_id) AS approximate_visitors,
 uniqExactIf(distinct_id,distinct_id!='') AS identified_users,
 min(created_at) AS first_event,max(created_at) AS last_event
FROM website_event
WHERE event_type=2 AND created_at>=now()-INTERVAL 30 DAY
GROUP BY event_name ORDER BY occurrences DESC LIMIT 35;

SELECT url_path,count() AS pageviews FROM website_event
WHERE event_type=1 AND created_at>=now()-INTERVAL 30 DAY
 AND url_path IN ('/registro','/register','/prueba-gratis','/login',
                 '/admin/login','/precios','/planes')

SELECT toStartOfMonth(created_at) AS month,
 countIf(event_type=1) AS pageviews,
 uniqExactIf(session_id,event_type=1) AS approximate_pageview_visitors,
 min(created_at) AS first_recorded_in_window,max(created_at) AS latest_in_window
FROM website_event WHERE created_at>=now()-INTERVAL 30 DAY
GROUP BY month ORDER BY month LIMIT 2;

SELECT hostname,event_name,count() AS occurrences
