name: Value of NUXA's prior bibliographic work
description: The user emphasises the importance of the bibliography developed for NUXA's responses.
---

El usuario describe el trabajo previo de NUXA como «un trabajo muy importante
con mucha bibliografía».

**Why:** Lo destacó al pedir analizar la potencia de las respuestas, después
de una propuesta de mejora del chat.

**How to apply:** Antes de proponer cambios en las respuestas, valorar el
trabajo bibliográfico existente y distinguir qué material se utiliza realmente
en la generación y qué material está disponible como biblioteca para el usuario.

Para el piloto, preferir documentación seleccionada y comprobada sin enviar
las preguntas personales a buscadores externos durante cada conversación.
No presentar la disponibilidad de un enlace ni pruebas con proveedor simulado
como prueba de precisión bibliográfica o eficacia clínica.

**Why:** Conectar el trabajo previo con las respuestas debe preservar privacidad,
control de costes y una distinción honesta entre integración técnica y calidad.

**How to apply:** Al ampliar las fuentes o cambiar la recuperación, comprobar
la correspondencia entre afirmaciones y documentos con respuestas reales;
las pruebas offline verifican el mecanismo, no la conducta del modelo.
