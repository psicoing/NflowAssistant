name: Alcance de inteligencia conversacional
description: Restricción del usuario para la siguiente etapa de NUXA/NEUROPSI-AI.
---

«A partir de ahora trabajaremos exclusivamente sobre la inteligencia conversacional de NUXA/NEUROPSI-AI. No modifiques interfaz, infraestructura, proveedores, pagos, voz, SEO ni otras funciones».

**Why:** El usuario ha fijado este alcance para la siguiente etapa del producto.

**How to apply:** Centrar orientación y propuestas en prompts, comprensión psicológica no diagnóstica, contexto, recuperación científica, seguridad y calidad de respuesta. Analizar el flujo existente antes de proponer cambios; una petición de orientación o análisis no autoriza implementación ni creación de tareas.
